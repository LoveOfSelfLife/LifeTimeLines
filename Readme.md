## Workout and program analysis

Open **Analyze** in the program or workout builder, or use the analysis action
in the corresponding library. Reports analyze saved definitions; save the
workout first, or save the program when editing a workout within a program.
New workouts cannot be analyzed until saved.

The shared report supports an optional RAMP inclusion toggle, objective
comparison, charts, and Excel, CSV, JSON, or printable exports. Selecting an
objective for a workout affects only that report; applying an objective to a
program remembers it for that program.
